# EPICS-Controlled Camera Characterization and Vision Platform

A Raspberry Pi Zero 2 W and IMX219-based project for learning and developing:

- EPICS-controlled camera acquisition
- quantitative camera characterization
- computer-vision applications
- hardware monitoring and alarm integration

## Planned Architecture

EPICS
→ Camera control/acquisition
→ IMX219
→ Image characterization
→ Computer vision
→ Monitoring/alarm

## Hardware

- Raspberry Pi Zero 2 W
- Sony IMX219 8 MP CSI camera
- LEDs and basic electronic components

## Project Areas

- `acquisition/` - camera acquisition and control
- `characterization/` - quantitative camera measurements
- `vision/` - LED recognition and hand-gesture experiments
- `epics/` - EPICS IOC and process variables

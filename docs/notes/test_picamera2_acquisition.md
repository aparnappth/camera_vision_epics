# Picamera2 — Image Acquisition Notes

## Objective

Understand still-image acquisition using Picamera2 before integrating acquisition commands into the EPICS IOC.

The standalone test is implemented in `acquisition/tests/test_camera_acquisition.py`.

## Acquisition Sequence

The implemented sequence is:

1. Open the IMX219 camera using Picamera2.
2. Create a still-image configuration with 180° rotation.
3. Apply the configuration using `camera.configure()`.
4. Set exposure time and analogue gain manually.
5. Start the camera using `camera.start()`.
6. Capture a completed request using `camera.capture_request()`.
7. Save the JPEG image and retrieve metadata from the same request.
8. Save the metadata in JSON format.
9. Release the request, stop the camera and close it.

## Image and Metadata from the Same Request

Two Picamera2 methods were considered:

- `capture_file()` captures an image and saves it directly to a file.
- `capture_request()` provides access to a completed capture request, including its image buffers and corresponding metadata.

The second approach was selected because quantitative camera characterization requires the image and acquisition metadata to correspond to the same frame.

```python
request = camera.capture_request()

request.save("main", str(image_path))
metadata = request.get_metadata()
```

The image is saved as a JPEG, while metadata is saved separately as JSON.

## File Organization

The script uses `pathlib` to save files in the same directory as the Python test script.

Each acquisition receives a timestamp-based filename:

```text
image_YYYYMMDD_HHMMSS_microseconds.jpg
image_YYYYMMDD_HHMMSS_microseconds_metadata.json
```

Matching filenames associate the image and metadata.

The filename timestamp is generated by the computer and is not the sensor's precise acquisition timestamp. Sensor timing information is available in the metadata.

## Manual Exposure and Gain

Automatic exposure was disabled using:

```python
camera.set_controls({
    "AeEnable": False,
    "ExposureTime": 20000,
    "AnalogueGain": 1.0
})
```

The camera metadata confirmed that the requested exposure and gain values were applied.

Compared with an earlier automatically exposed image, the manually exposed image was considerably darker.

Systematic exposure and gain characterization will be performed later through EPICS.

## Resource Management

The script uses one `try`/`finally` block to release acquisition resources.

- `request.release()` releases the captured request and its buffers for reuse.
- `camera.stop()` stops the camera streaming pipeline.
- `camera.close()` releases camera resources.

Although the standalone script captures only one image per execution, explicit request release will become important when repeated acquisitions are implemented through EPICS.

## Current Scope and Limitations

- One still image is captured per script execution.
- Image and metadata originate from the same completed request.
- Images are saved as processed JPEG files rather than raw sensor data.
- Exposure time and analogue gain can be configured manually.
- Image acquisition has not yet been integrated into the EPICS IOC.
- The current script is a standalone test, not an automated characterization procedure.
